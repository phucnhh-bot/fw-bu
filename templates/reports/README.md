# Template báo cáo

Mỗi loại báo cáo một file `<report-id>.md` (vd `doanh-thu-thang.md`, `kpi-van-hanh.md`). Template quyết định cấu trúc và câu chữ; số liệu được điền lúc build và hiển thị theo design system chung. Loại báo cáo chưa có template dùng giao diện mặc định.

- Cú pháp (frontmatter, `{{ biến | currency }}`, khối ```kpis/```chart/```table, callout): `.claude/skills/business-report-html/references/markdown-template.md`
- Ví dụ: `mau-doanh-thu.md` (xoá hoặc thay khi có template thật)
- Hướng dẫn: `instruction/report-templates.md`
